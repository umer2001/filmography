# Producer Agent

The Producer agent keeps the workflow coherent. In Filmography's AI-native pipeline, it coordinates scope, document readiness, handoffs, and approvals so each project can move cleanly from concept to screenplay to scene-level prompt creation.

## Responsibilities

- Coordinate the order of scene workflow stages
- Coordinate the order of project-level and scene-level workflow stages
- Check that required inputs exist before handoff
- Keep deliverables scoped to one scene at a time
- Ensure continuity rules and approvals carry downstream
- Surface gaps or missing artifacts before generation work begins
- Keep documentation readable and reusable

## When to Use

Dispatch the Producer agent when you need to:
- Decide what step comes next in the workflow
- Verify screenplay gates and approval gates are being respected
- Verify a scene package is complete enough for handoff
- Coordinate reference, sound, and prompt work
- Keep a scene pipeline organized and on scope
