# Environment Description

- Name: Laundromat
- Project: Borrowed Light
- Role in story: Intimate confrontation space where routine and repair collide

## 2. Core Description
- What the environment is: A small urban late-night laundromat with a metal folding counter and rows of lit washers
- Emotional feeling: Lonely, practical, slightly suspended in time
- Time-of-day patterns: Primarily night

- Palette: Steel blue, off-white, muted practical colors

- Signature details: Rain-streaked front windows, rotating washer glow, sparse occupancy

## 4. Recurring Objects Or Props
- Story-relevant props: Dented cassette case, folded diner uniforms
- Repeating environmental markers: Washer lights, fluorescent hum, bell at the front door

## 5. Downstream Notes
- What scene-level workflows should preserve: Grounded realism, visible rain, modest scale, and restrained intimacy
