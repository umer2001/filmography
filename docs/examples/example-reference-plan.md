# Reference Plan

## 1. Scene Identity
- Project: Borrowed Light
- Scene ID: SC-04
- Scene Title: Laundromat Promise
- Version: v1

## 2. Reference Strategy
- Why references are needed for this scene: The emotional subtlety depends on stable faces, wardrobe, fluorescent color tone, and a consistent cassette prop.
- Main continuity risks: Ray's wetness drifting between shots, Sana's uniform details changing, cassette damage disappearing, laundromat palette shifting
- Reuse strategy across shots: Reuse the same character and environment anchors for every shot; add only one bridge-frame pair for the stitched shot
