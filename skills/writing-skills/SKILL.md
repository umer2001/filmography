# Writing Skills

## Overview

Filmography skills are reusable workflow guides, not one-off clever prompts. A good skill should tell an agent when it applies, what inputs it requires, what outputs it should produce, and what it must not change.

## Required Qualities

- Solve a real production problem
- State the trigger clearly
- Define upstream inputs and downstream handoffs
- Protect locked story, continuity, or approval constraints
- Point to reusable templates or contracts when needed
- Stay broad enough to help multiple productions

## Skill Checklist

- Add valid frontmatter with a trigger-focused description
- Explain required inputs
- Explain expected outputs
- Call out hard gates and forbidden moves
- Show how the skill collaborates with adjacent stages
- Add or update example artifacts when the workflow changes materially

## Rule Of Thumb

If another agent cannot tell where the skill starts, where it stops, and what document it hands off, the skill is not finished yet.
